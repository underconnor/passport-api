# 운영 검증과 후속 확장

실제 학교 SSO 토큰 교환·최소 신원 파싱, HMAC 명부 대조, 원자적 snapshot 동기화, 관리자 TOTP·권한 관리·감사 조회와 정책 outbox cursor API를 구현했다. 세부 계약은 [runtime-api.md](runtime-api.md)에 기록한다.

## 실제 배포 완료 조건

1. HTTPS에서 사용자가 직접 학교에 로그인하고 callback·학번 대조·세션 회전을 확인한다. 학교 비밀번호·토큰·원본 HTML은 기록하지 않는다.
2. 실제 명부 매칭과 명부 밖 계정의 차단을 확인한다. 이미 구현한 자동 동기화의 실패·만료·대량 변경 승인도 검증한다.
3. 운영자 본인이 등록 코드와 인증 앱으로 최초 TOTP 등록·재인증을 완료한다.
4. 정품 Java 클라이언트로 NanoLimbo 안내→웹 확인→게임 확인→보호 서버 이동과 접속 중 회수·API 장애를 시험한다.
5. 운영 ingress의 TLS·프록시 hop·콜백 로그 제외·개발 인증 차단을 확인하고 DB 백업을 별도 환경에 복원한다.

## 확장 범위

- 다중 API replica를 위한 공유 요청 제한과 worker 잠금
- 여러 운영자 초대·권한 세분화 및 승인된 MFA 복구
- 다른 서비스의 공통 로그인/OIDC 제공
- 학교 응답 형식 변경 감지와 개인정보 없는 상태 관측

구현·자동 검사·실제 계정 QA·전체 인터넷 공개 여부는 각각 기록한다.
