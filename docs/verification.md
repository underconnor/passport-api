# 첫 개발 배포 검증

2026-09-30, 합성 회원만 사용하는 격리 개발 환경 기준입니다.

- 단위·명부 파서 7개와 전용 PostgreSQL 통합 13개가 통과했습니다.
- Linux 컨테이너에서 독립 Docker build, migration, 명시적 development seed, DB health check를 확인했습니다.
- 실제 사용자 웹 프록시와 배포 API를 통해 HTTP 검사 24개를 통과했습니다. 웹 확인만으로는 접근을 허가하지 않고, 다른 게임 세션은 403, 양쪽 확인은 연결 완료, 재사용은 409를 반환했습니다.
- 배포 정책 응답은 JSON Schema에 부합했습니다. 개발 게임 서버의 실제 Java HTTP client로 정책을 조회하고 미연결 UUID가 허가되지 않는 것을 확인했습니다.
- 사용자 브라우저에서 합성 로그인, Discord ID 저장·새로고침·삭제, uint64 초과 거절, 로그아웃, 비회원의 빈 서버 목록, 관리자 접근 차단을 확인했습니다.
- 포털과 관리자 쿠키가 같은 호스트의 다른 포트에서도 분리되며 학교 토큰·서비스 비밀을 프런트에 제공하지 않습니다.

실제 u-SAINT 계정, Google Sheets 회원 반영, 관리자 MFA, 정품 Minecraft 클라이언트의 전체 접속과 서버 이동은 아직 검증하지 않았습니다. 학교 경로는 503, 관리자 작업은 403으로 닫혀 있습니다. 이 결과는 운영 인증 완료를 뜻하지 않습니다.

UI는 후속 디자인 변경과 별도로 다시 검증합니다. GitHub Actions 결과는 실행한 commit의 run 상태를 기준으로 판단합니다.

## 실제 연동 구현 검사 — 2026-09-30

- 실제 학교 로그인 화면·익명 포털 HTTP 응답을 확인했다. 실제 학교에 보낸 잘못된 토큰은 거절되었다.
- 공식 로그인 토큰 교환·SAP 쿠키·학교 렌더링 학번 대조 어댑터, 최소 정보 파서의 단위 검사를 통과했다.
- 실제 Google 명부의 필요한 두 열만 읽어 36명을 검증했고, 분리된 실제 인증 DB의 첫 snapshot 36개 반영을 확인했다. 학교 인증을 완료한 Subject는 아직 생성하지 않았다.
- 단위·파서·TOTP·암호화 검사 28개 통과. 통합 테스트 전체 명령에서 PostgreSQL HTTP/게임 14개, 명부 원자 반영 10개, 학교 세션·관리자 MFA/정책 13개로 총 37개 통과.
- 학교 HTTP 통합 테스트는 테스트 프로세스에서만 합성 학교 응답을 주입한다. 실제 Google 읽기 성공이나 파서 단위 성공을 실제 사용자 학교 로그인 완료로 계산하지 않는다.
- 학교 state·현재 브라우저 결합·만료·동시 콜백 단일 성공·토큰 재사용 차단·세션 회전·암호화 링크 복귀를 확인했다.
- 최초 운영자 단일 등록, TOTP 등록키 암호화, MFA 후 쿠키/CSRF 회전, 코드 재사용 거절, 실패 잠금, 정지·서버 제한·연결 해제·감사 actor 기록을 확인했다.
- outbox cursor의 초기 동기화·범위 초과·보관 기간 경과·DB 복원 초기화와 서비스 인증을 확인했다. 이벤트는 정책 조회를 유도하며 직접 허가하지 않는다.

사용자 본인의 학교 로그인·관리자 인증 앱 등록·정품 Minecraft 접속 왕복은 준비된 HTTPS 환경에서 별도 수행한다. 인터넷 공개 여부와 해당 실사용 시험 결과는 배포 기록에서 구분한다.
